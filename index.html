Adaptive payment-gateway router

Razorpay · 2026

This router selects a payment gateway for each transaction. It learns from the result of every transaction. If a gateway starts to fail, the router moves the traffic to a better gateway. In a simulation with 10 million transactions, its success rate was about 2.2 times the success rate of a threshold router. I tested it in shadow mode before the release.

Driver churn prediction

Namma Yatri · 2024–2025

This model calculates a churn risk for each of about 150,000 drivers every morning. It uses 36 features and two algorithms: XGBoost and a random forest. The operations team calls the drivers with the highest risk. In three months, the monthly churn decreased from 42% to 30%. The calls also showed why the drivers stop, and this caused changes to the prices and to the driver matching.

Driver safety enforcement

Namma Yatri · 2024–2025

Riders send feedback in Kannada, Hindi, and English. The Sarvam API translates the text to English, and a classifier puts each complaint in one of five severity groups. For a small problem, the system decreases the priority of the driver in the ride matching. For a serious problem, a person examines the case and can block the driver. Safety complaints decreased by about 50%. The system gave a lower priority to about 12,000 drivers and blocked about 550 drivers.

Slack-native AI analyst

Razorpay · 2025–2026

I put more than 2,000 documents into one data wiki. A person must approve each page before the agent can use it. In Slack, the agent reads the index, opens the related pages, and writes an SQL query. Voice AI support agent

Namma Yatri · 2024–2025

Drivers speak to a voice agent when they need help. The agent uses Gemini Live and answers in less than one second. It speaks more than one language. If it cannot solve the problem, it sends the call to a person. The resolution time decreased by 75% and the driver NPS (Net Promoter Score) increased by 18 points.

The model examines the type of the offer, the time, and the product. Uber used these scores to select the offers in the Asia-Pacific region. The net revenue for each outlet increased 3 times.

Fantasy Premier League player-performance models

Personal · 2026

These models predict the points of each Fantasy Premier League player in the next gameweek. They use 79 features that are available before the deadline. A walk forward backtest of 75 gameweeks measures the quality. The best team gets about 10% more points than a simple baseline. The tests also found two problems in the data: one column contains information from after the match, and the availability feature did not improve the results.
